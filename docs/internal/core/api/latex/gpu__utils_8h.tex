\doxysubsection{Detailed Description}
Reusable RAII helpers for Web\+GPU/\+Dawn compute work. 

This layer sits on top of the \doxylink{classGPU}{GPU} singleton (\doxylink{gpu_8h_source}{gpu.\+h}) and eliminates boilerplate that every compute kernel otherwise duplicates\+:
\begin{DoxyItemize}
\item typed buffer creation, upload, and blocking readback
\item texture creation, upload, and aligned readback
\item bind-\/group construction from a simple list
\item compute-\/pass encoding and single-\/shot dispatch
\end{DoxyItemize}

All helpers live in the {\ttfamily gpu} namespace and are internal to the library.
