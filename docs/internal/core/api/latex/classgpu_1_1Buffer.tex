\subsubsection*{template$<$typename T$>$\newline
class gpu\+::\+Buffer$<$ T $>$}
RAII wrapper around a wgpu\+::\+Buffer with compile-\/time type safety. 

T must be a trivially copyable type. The buffer is destroyed when this object goes out of scope.
